The initial control loop

Nine steps, in order. Each one leaves a tenant-scoped record — the authorization decision, the execution result, the retest result, the evidence.

Discover→Identify→Map Reach→ Evaluate Policy→Decide→Authorize Execution→ Observe→Retest→Prove

A system is not complete because a dashboard state changed. The record, the decision, the execution and the evidence must exist in the connected path.

What gets governed

The initial security surface is deliberately narrow: the agent and MCP paths where a wrong decision reaches real systems.

Inventory

Agents, servers, tools

  • Agent discovery and inventory

Distinction

Adapter ≠ integration

A connector reads INTEGRATED only after real credentials and a live authenticated provider path are verified. Until then it stays BLOCKED, UNKNOWN or UNMEASURABLE.

Evidence controls, not marketing labels

REO

Retest, then prove

Evidence-backed retesting of a real reachable or exploitable condition, plus proof of the resulting security state.

RIO

No invented numbers

Observed security outcomes are kept separate from customer-approved financial assumptions. If the inputs are missing, no financial result is produced.

ROE

Rules of engagement

Authorized validation activity: scope, approvals, evidence and release/runtime testing boundaries.

Production truth

Production mode uses real connected records only.

Never

No mock data

  • No placeholder success states
  • No invented customers, findings, savings or rankings
Always

Unknown stays unknown

Missing or unavailable evidence remains UNKNOWN, UNMEASURABLE or INSUFFICIENT_REACH as appropriate — visible in the product, not smoothed over in a summary.

Deploy

The repository seeds nothing on startup. Empty or disconnected production state stays empty or explicitly unavailable until you supply DATABASE_URL, run migrations and verify the connected tenant path.

The security boundary

The model or agent is not the security boundary. Identity, policy, authorization, execution controls, evidence and verified runtime outcomes form the boundary.

Scope discipline: nothing is scanned, probed or tested without written authorization and a defined scope. Unsolicited testing is not a service I offer — to anyone.
